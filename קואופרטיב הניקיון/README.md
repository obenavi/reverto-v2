# כספי הקואופרטיב

אפליקציה לאיחוד נתונים כספיים מכמה מערכות. היא בונה דוח רווח והפסד מאוחד, משווה ביצוע לתקציב ומפיקה תובנות עסקיות.

## הפעלה

פותחים את `index.html` בדפדפן, בלי התקנה ובלי שרת. הקבצים נקראים בדפדפן ונשמרים רק בו, ולא נשלחים לשום שרת.
בפתיחה הראשונה מוצגים נתוני דוגמה של קואופרטיב ניקיון. הכפתור "ניקוי נתוני הדוגמה" מסיר אותם.

## תהליך העבודה

1. **מקורות נתונים**: מעלים קבצי ייצוא (xlsx, xls, csv) מה-ERP, מהבנק, ממערכת השכר, מה-CRM או מגיליונות ידניים.
   המערכת מזהה אוטומטית את שורת הכותרות ואת העמודות: תאריך, סכום (או חובה/זכות), חשבון, תיאור ומחלקה.
   את הזיהוי אפשר לתקן, והתצוגה המקדימה מראה בדיוק מה ייקלט. קבצי CSV בקידוד עברי ישן (windows-1255) נתמכים.
2. **מיפוי סעיפים**: כל חשבון או תיאור מכל מערכת משויך לשורה בדוח (הכנסות, עלות השירות, שכר, תפעול, הנהלה וכלליות, מימון, אחרות או "לא לכלול").
   הסיווג האוטומטי מבוסס על מילות מפתח, ושינוי ידני נשמר.
3. **הזנת תקציב**: אפשר להקליד את התקציב ישירות בטבלה, או לייבא מאקסל: עמודה ראשונה עם שם הסעיף ועמודה לכל חודש.
4. **הדוחות**:
   - **סקירה ותובנות**: מדדים מרכזיים, גרף חודשי, רווחיות לפי מחלקה ותובנות אוטומטיות. התובנות כוללות סטייה מהתקציב, הסעיף שחרג יותר מכולם, יחס שכר להכנסות, קפיצות בהוצאות, תחזית לסוף השנה, כפילויות בין מערכות ותנועות לא מסווגות.
   - **רווח והפסד**: דוח חודשי מאוחד עם רווח גולמי, רווח תפעולי ורווח נקי, מול התקציב.
   - **תקציב מול ביצוע**: סטייה בש״ח ובאחוזים לכל סעיף, עם סטטוס ברור.

## כללים חשובים

- **מניעת ספירה כפולה**: מקור מסוג בנק לא נכלל בדוח כברירת מחדל, כי התנועות שלו בדרך כלל כבר רשומות ב-ERP. אפשר לשנות זאת בכרטיס המקור.
  בנוסף, המערכת מסמנת תנועות שנראות כפולות: אותו סכום בשני מקורות, בהפרש של עד 3 ימים.
- **סימנים**: הכנסה נשמרת כסכום חיובי והוצאה כסכום שלילי. בדוח ההוצאות מוצגות כמספר חיובי.
- **ייצוא**: "ייצוא לאקסל" יוצר קובץ עם הדוח ועם כל התנועות המאוחדות. "העתקת הדוח" מעתיקה את הטבלה להדבקה באקסל.

## הרחבות אפשריות

- חיבור API ישיר למערכות (למשל פריוריטי, SAP או ממשקי בנקאות פתוחה) במקום ייצוא ידני.
- תקציב ברמת מחלקה.
- דוח תזרים מזומנים על בסיס נתוני הבנק.
- שמירה בענן ושיתוף עם צוות הכספים.
