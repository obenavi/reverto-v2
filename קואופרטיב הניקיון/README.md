# כספי הקואופרטיב

רווחיות לפי לקוח וסניף, מחושבת משלושה דוחות חודשיים:

| דוח | מקור | מה נלקח ממנו |
|---|---|---|
| דוח הכנסות | הנהלת החשבונות | הכנסה לפני מע"מ לכל לקוח. חשבוניות הזיכוי מקוזזות. |
| דוח משימות | TimeWatch (קובץ HTML עם סיומת ‎.xls) | שעות לכל אתר (משימה) וסניף האתר |
| דוח שכר | מערכת השכר, גיליון הפיצול לפי "משנה" | עלות מעביד לכל אתר. גיליון "דוח מעסיק" משמש לאימות |

## איך זה עובד

1. **קליטת נתונים:** מעלים את שלושת הקבצים. סוג הדוח והחודש מזוהים אוטומטית.
   לכל דוח מוצגות בדיקות: סכומים מול שורות הסיכום, פיצול השכר מול דוח המעסיק, ומשמרות חריגות.
   נשמרים רק סיכומים לפי לקוח ואתר, בלי פרטי עובדים.
2. **התאמת לקוחות:** כל לקוח מחבר אתרים (לפי הקוד בסוגריים, שזהה ב-TimeWatch ובשכר) לשם אחד או יותר בהנהלת החשבונות.
   אתר או שם חדש שלא שויך מופיע ברשימת "ממתינים להתאמה". אתר 999 (הנהלה) נספר כעלות הנהלה.
   את טבלת ההתאמה אפשר לייבא מאקסל ולייצא לאקסל. העמודות: קבוצת לקוח, קודי אתרים, לקוחות בהנהלת החשבונות (מופרדים ב-|).
3. **סקירה ותובנות:** רווח גולמי לפי סניף ורווח אחרי שכר הנהלה. התובנות כוללות לקוחות בהפסד, רווח נמוך, עלות שעה חריגה,
   הכנסה לשעה מחוץ לטווח ₪60–90 (סימן להתאמה חסרה) והשוואה לחודש הקודם.
4. **רווחיות לקוחות:** טבלה שאפשר למיין ולסנן לפי סניף. לחיצה על לקוח מציגה את האתרים שלו.
5. **תקופות:** חודש (מול החודש הקודם), רבעון (מול הרבעון הקודם) ומצטבר מתחילת השנה (מול התקופה המקבילה אשתקד, כשיש נתונים).
   בתקופה של כמה חודשים הסכומים מתחברים לפי לקוח, אתר וסניף, והשיעורים והסטטוסים מחושבים מחדש על הסכום.
   מוצג גם פירוט לפי חודש. חודש שלא נקלט, או דוח חסר, מסומנים כחישוב חלקי.

הסניף של הכנסה נקבע לפי האתרים של הלקוח. לקוח שיש לו אתרים בכמה סניפים מתחלק ביניהם לפי חלק השעות.

## אחסון

- **בעמוד שפורסם ב-claude.ai:** הנתונים נשמרים במאגר המשותף של הדף וזמינים לכל מי שהדף משותף איתו.
- **בפתיחה מקומית של הקובץ:** הנתונים נשמרים בדפדפן בלבד.

נתוני הלקוחות והשכר לא נשמרים ב-git.
